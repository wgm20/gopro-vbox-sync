Free · Open source · Windows · Beta

Match recordings using GPS time, choose the runs you want, and add telemetry to higher-resolution video.

Circuit Tools 3 compatibility is still in beta. Circuit Tools can reject generated VBO files with an authenticity/checksum error and may close. This remains unresolved. Re-encoding is not a proven fix. A successful export verifies the app's output, not acceptance by Circuit Tools. Test a short run before processing a full day.

Install once. Work locally.

  1. Download the Windows Setup.exe from the official releases page. You do not need Python or a GitHub account.
  2. Run the installer. It installs for your Windows account and adds a Start menu shortcut. A desktop shortcut is optional. Choose Help → Uninstall app to open the normal Windows uninstall confirmation. The app closes so its files can be removed. Recordings, exports, settings and downloaded video tools are retained. For a portable copy, close the app and delete its extracted app folder; keep your recordings and exports separately.
  3. Open GoPro VBOX Sync. If video tools are missing, the app offers a 110 MB download of FFmpeg and FFprobe from Gyan's GitHub release, with an integrity check. Allow about 500 MB free space for setup. If either tool is missing when you scan or try the demo, the app offers this download and resumes after setup. You can also choose Help → Set up video tools. Internet access is needed for the download; processing then works offline.

Windows 10/11, 64-bit Intel/AMD. This beta installer is unsigned, so Windows may display an unknown-publisher warning. Verify the official download and its published SHA-256 before deciding whether to install. ARM Windows is not tested.

1Choose recording folders

Choose the folder containing your VBOX runs. GoPro videos starts with that folder automatically. For GoPro files elsewhere, browse for an SD card, its DCIM folder or any other folder, or type its path. There is no need to copy the GoPro files.

The GoPro folder follows your VBOX folder until you choose or type a separate location. The app remembers that location when you reopen it. Clear GoPro videos to use the VBOX folder again; it fills in when you scan or choose another VBOX folder.

GoPro subfolders are searched by default, including the card's camera folders. Change this under Options → Include GoPro subfolders; the app remembers your choice. Check both folder paths, then click Scan for matches beneath them. This finds matching runs before you choose videos to convert.

VBOX runs are read from the top level of their chosen folder. Keep the original VBOX videos beside the VBO files for sound and cropping. Keep the GoPro camera originals; edited movies may lose GPS metadata. GPS must have been enabled and recorded a usable fix.

2Select your runs

Compare Date, Start and Best in file before starting a conversion. Recording dates and start times come from GoPro GPS timestamps. Choose local time or UTC; recordings start in chronological order, and clicking a column heading sorts the list.

Best in file is the fastest complete VBOX lap wholly within that GoPro file's GPS time range. Laps split across files are excluded; — means no complete lap is available. A separate red star (★) marks footage of the whole-run fastest lap. If that lap spans files, both are marked; include them together to keep the complete lap. Options → Details… shows the whole-run best and explains partial coverage. Options → What do red stars mean? explains the markers.

All matched videos start ticked. Untick Include to skip a video; Space toggles the focused row. Export video lists only ticked, matched files. One is selected automatically when it is the only choice. With several, choose from that list or click an included table row. Rotation and framing always apply to this export video. Highlighting an excluded row does not change it; Options → Details… can inspect any highlighted row.

Lap times are reconstructed from VBOX data using the overlay’s timing method and may differ from the recorder. Incomplete laps and laps crossing data gaps are excluded. A missing start/finish line or complete lap shows —; Options → Details… explains why. These details are calculated during scanning, before video conversion. Only ticked files are exported. With none ticked, the preview clears and rotation, framing and Create files are disabled.

3Preview and create

Choose the file under Export video, then use Options beside Help for Resolution, Overlay and Sound. The main Export preview shows a finished still with the crop, rotation, resolution and overlay applied. Its heading shows the output width and height in pixels. It updates when you change these settings or choose a scene; a rendering problem is explained instead of showing an unfinished camera image. Options → Only export video with VBOX data is ticked by default: it removes footage before and after matching periods. Untick it to keep the full videos. Check that the still is upright, all gauges fit and their units are correct. Open Frame & preview… to adjust the chosen file’s crop, then click Apply to this video. Choose each export video in turn to check its own framing, select Save to, then Create files.

The default output is a new folder under your VBOX folder, even when reading GoPro files from an SD card. Keep that card or drive connected until processing finishes. Open Report for checks and warnings. Keep each generated MP4 beside its VBO when moving or sharing the result. Open the VBO in Circuit Tools 3 for analysis; the MP4 also plays in ordinary video players.

If enabled crops exist only on excluded files, Create files asks Export without the saved crop? and defaults to No. Choose No to review which files are included and how each is framed.

Source recordings are not modified. Use a new output folder after changing settings or the included videos. Cancellation leaves an incomplete working folder with diagnostics; it does not publish a finished result.

Learn with two practice recordings

Choose Help → Try practice recordings. The app copies the bundled synthetic videos and data to a fresh practice folder and scans them. No real driver footage or recorded locations are included.

  1. Leave both videos ticked. Choose each under Export video and check its finished still.
  2. Untick the first run. Notice that the included count and overlap change.
  3. Choose Options → Overlay → Driving data, with Scene blank, and inspect Export preview. Open Frame & preview… if you want to adjust the framing.
  4. Create files and open the MP4. Only your included run is exported.

Only overlapping VBOX samples are linked. By default, output video contains only matching periods, including the frames containing the boundary samples. Separate periods use separate clips. VBOX video times are adjusted automatically. Untick Options → Only export video with VBOX data to retain whole video chapters; the overlay disappears outside data coverage. This demo tests matching and video output; it cannot prove recorder authenticity.

Your finished files

The finished folder contains only MP4 videos and VBO data files. Keep them together when opening a VBO in Circuit Tools or sharing the result. Use the app’s Report button for the export summary. Reports, preview images and diagnostic logs stay in the app’s local data folder on this computer.

Choose the sound

Choose sound under Options → Sound. VBOX (GoPro for gaps) is selected by default. Keep the original VBOX MP4 files beside their VBO files. The app follows the VBO video references and GoPro GPS timestamps to align the sound, including recording prebuffer, trimming, chapter changes and clock drift. It does not use the numbers burned into the original picture as a timing reference.

If a VBOX video is missing, has no sound or has unreliable timing, GoPro sound fills that period. The report lists the source files and affected periods. If neither recording has sound, that period is silent. Choose Options → Sound → GoPro to use the camera’s own sound throughout. The app remembers your choice.

Choose the picture you want

Drag to frame your video. Keep the original VBOX videos beside the VBO files, choose a ticked file under Export video, then open Frame & preview…. The editor heading names that file; framing applies to this file only. Tick Crop to VBOX and drag the outlined box on the left. The right pane shows the finished picture with your selected overlay. The crop keeps the original VBOX proportions, normally 16:9. Arrow keys make small adjustments; Shift + arrows moves further. Centre crop resets the position. Click Apply to this video to use it for the named file, or Cancel to keep its previous framing. Choose another Export video to adjust its framing separately. Untick cropping to retain the whole image.

Rotation is applied before cropping, and overlays are fitted afterwards. Cropping changes the picture, not the timing or data. The Options → Only export video with VBOX data setting trims time: sound, overlays and VBOX links are adjusted together, and full-session data remains available for lap history. Each video has its own choice. Cropping needs all original VBOX video chapters linked to the matched data to have the same shape; see Options → Details… if it is unavailable.

OverlayWhat appears
NoneCorrected video without data burned into the picture.
Driving dataSpeed, RPM, throttle and brake. Leave Scene blank for the built-in dashboard (mph, rpm, %, psi), or choose a supported scene. Your VBO must contain the required channels and compatible units.
Full scene · no rear cameraSupported gauges, artwork, G-ball, track map and lap/delta timing from your selected scene. Rear-camera picture and its border are excluded. Uniform scaling preserves gauge and map proportions.

Open your VBOX scene. Choose Options → Overlay → Full scene · no rear camera and select a .VVHSN scene in Scene. The main Export preview updates automatically; open Frame & preview… when you want to adjust framing. Install a compatible version of VBOX Video Setup and its .NET 8 Windows Desktop Runtime first. The app uses the editor’s public scene importer; a previously saved copy is not required. PowerShell 7 and a .NET SDK are not needed.

A .gvscene saved scene package remains another option. It contains configuration, artwork and fonts from an earlier import and opens locally without VBOX Video Setup. Keep a copy and share it only when you have permission to share its contents. Vendor libraries and private scene packages are not bundled with the app.

Vendor library versions can differ; a missing importer or runtime is reported before export. Driving data with Scene blank uses the built-in dashboard. Scene support covers a tested subset; unsupported widgets, required channels or units stop export with an explanation. Derived lap/delta and G-ball values can differ from the recorder.

Full resolution keeps the pixels remaining after rotation and cropping. All modes encode a new H.264 video with compression loss. HD and Compact limit the longest edge to 1920 and 1280 pixels. No option copies the original compressed stream.

If something needs attention

What you seeWhat to do
No matchesOpen Options → Details…. Check both source folders. Check Options → Include GoPro subfolders if the camera files are inside DCIM or other subfolders; it starts ticked. VBO files must be directly in the VBOX folder. Recordings must be from the same vehicle and time. Filenames do not supply recording times. GPS-less GoPros, including HERO12, cannot be matched automatically.
Duplicate GoPro filenamesThe scan lists the conflicting paths. Choose a more specific GoPro folder containing the recordings you want, then scan again. This keeps separate clips with identical filenames from sharing selection or export settings.
SD card or source unavailableReconnect the card or drive, check both chosen folders and scan again. Leave the source connected throughout export.
Choose rotationChoose the file under Export video, inspect the finished still, then choose the correct rotation. The app defaults to no rotation; visually check every run and change it if necessary.
Scene importer or runtime unavailableInstall or update VBOX Video Setup with its .NET 8 Windows Desktop Runtime. The installed version must expose the public scene importer. Read Options → Details… for the missing component; a saved .gvscene package or Driving data with Scene blank remains available.
Missing channels / unsupported sceneCheck the scene, VBO channel names and units. Try Driving data with Scene blank, or None if the data lacks throttle, RPM or brake.
Output folder already existsAn identical verified rerun may be reused. Otherwise choose a new name in Save to. Existing results are protected.
Video tools unavailableUse Help → Set up video tools. Check the connection and free disk space. For offline use, an existing FFmpeg/FFprobe installation on PATH or in Circuit Tools 3 is supported.
Circuit Tools checksum errorThis is a known unresolved limitation. The MP4 can still be viewed separately. Keep the originals. Do not interpret successful export checks as a checksum fix.
Unexpected failureRead Options → Details… and use the Report button. Describe your camera model, app version and error in a GitHub issue. Review logs before posting: they may contain filenames, local paths and GPS data. Share only material you intend to make public.
